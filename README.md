## 🧠 What is an AI Agent?
An AI agent is a system that can **perceive**, **reason**, 
and **act** autonomously to complete tasks — going beyond 
simple chatbots to take real-world actions.

## 🚀 Popular AI Agent Frameworks

- [LangChain](https://langchain.com) - Most popular framework 
  for building LLM-powered agents
- [AutoGen](https://github.com/microsoft/autogen) - Microsoft's 
  multi-agent conversation framework
- [CrewAI](https://crewai.com) - Framework for orchestrating 
  role-playing AI agents
- [LlamaIndex](https://llamaindex.ai) - Data framework for 
  LLM-based agents
- [SuperAGI](https://superagi.com) - Open source autonomous 
  AI agent framework
- [AgentGPT](https://agentgpt.reworkd.ai) - Browser-based 
  autonomous AI agent
